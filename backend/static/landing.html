Frequently Asked Questions

Got Questions? We Have Answers.

How does AegisDAST differ from traditional scanners like OWASP ZAP or Burp Suite?

+

Traditional scanners lack domain workflow awareness: they inject standard payloads into single parameters and produce high false positives while completely missing multi-step logic flaws. AegisDAST crawls the state machine (Search → Hold → Book → Pay → Cancel) with multiple authenticated test personas, understands business constraints, and strictly tests cross-tenant boundaries.

Is it safe to run against production or staging environments?

+

Yes. Phase 3 implements an enterprise-grade Safety Guard layer featuring a strict Host Allowlist, Token Bucket Rate Limiter (with refill smoothing), and an automated Latency/Error Circuit Breaker that trips if 5 consecutive 5xx errors or 3000ms latency spikes are detected.

What is the cryptographic audit log and why does it matter?

+

Every request, response status, and test execution is linked into an append-only SHA-256 hash chain (similar to a blockchain ledger). If an auditor or security engineer questions whether a security check was executed or tampered with, the cryptographic chain provides tamper-evident mathematical proof.
